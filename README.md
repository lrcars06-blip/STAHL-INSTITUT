# Beauté & Technologie Stahl — site vitrine

Site statique d'une page : `index.html` + images, tout à la racine, aucune compilation.

## Mettre en ligne

1. Sur GitHub : **New repository**, puis **uploading an existing file** et glisser tous les fichiers de ce dossier.
2. Sur Vercel : **Add New > Project**, importer le dépôt, laisser les réglages par défaut, **Deploy**.
   (Ou GitHub Pages : Settings > Pages > branche `main`, dossier `/root`.)

## Modifier

- Lien de réservation : constante `PLANITY_URL` en bas de `index.html`.
- Carte des soins : tableau `CARTE` dans le script de `index.html`.
- Images : remplacer un fichier `.jpg` en gardant le même nom.

## Crédits images

- Photos de l'institut et de l'équipe : fiche Planity de l'institut (accord de la gérante requis avant mise en ligne).
- Photos d'illustration `soin-visage`, `soin-pinceau`, `fontaine-zellige`, `modelage`, `argile` : Unsplash (licence Unsplash).
